# 流式视频分析功能测试清单

## 测试环境准备

### 1. 加载扩展
1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择项目的 `dist/` 目录
6. 确认扩展加载成功，图标出现在工具栏

### 2. 配置 API
1. 点击扩展图标，选择"选项"
2. 或右键扩展图标 → 选项
3. 配置以下信息：
   - API 密钥：输入智谱 AI API Key（必需）
   - API 地址：`https://open.bigmodel.cn/api/paas/v4`（默认）
   - 模型 ID：`glm-4.6v-flash`（默认）
   - 最大 Token 数：1000（默认）
   - Temperature：0.7（默认）
4. 保存设置

## 功能测试

### 测试用例 1: 基础流式分析

**前置条件**: 已配置有效的 API 密钥

**步骤**:
1. 访问任意 B站视频页面（如: `https://www.bilibili.com/video/BV1xx411c7mD`）
2. 等待页面加载完成
3. 查看是否出现"AI摘要"按钮（浮动在页面右侧）
4. 点击"AI摘要"按钮

**预期结果**:
- ✅ 立即弹出模态框
- ✅ 模态框标题显示"🎬 视频分析中..."
- ✅ 显示加载动画（旋转的 spinner）
- ✅ 状态标签显示"生成中"
- ✅ 复制按钮为禁用状态
- ✅ 几秒后开始逐段显示 AI 分析结果
- ✅ 内容逐块追加显示（无打字机效果，直接显示）
- ✅ 自动滚动到底部（如果用户未向上滚动）
- ✅ 分析完成后，状态变为"已完成"
- ✅ 标题变为"🎬 视频分析结果"
- ✅ 复制按钮变为可用状态

**可能的问题**:
- ❌ 按钮未出现 → 检查 content script 是否注入
- ❌ 模态框未弹出 → 检查控制台错误
- ❌ 无内容显示 → 检查 API 密钥、网络连接、API 配额
- ❌ 内容显示异常 → 检查 SSE 解析逻辑
